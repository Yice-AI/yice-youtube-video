# 高留存叙事与三态画面

在逐句配音前先写清五拍。第一拍展示一个能被复核的成品，用观众马上能看懂的动作回答“值得看吗”。第二拍让失败真实发生，例如点击截图里的标题却无法编辑。第三拍只给一条解决路线，让镜头抵达第一步。第四拍交替展示输入、执行、真实效果与机制。末拍诚实交代边界，再把已经见过的产物收拢交付。

| 形态 | 观众看到什么 | 教程时长占比 |
|---|---|---|
| M1 空间合成 | 真实贴图环绕、抽选，或页面骨架与原生文本在深度方向分别移动 | 至少 15% |
| M2 实操 | 真实录屏中的一次输入、点击、修改或导出。终端面板保持精炼 | 30%–58% |
| M3 流程动画 | 路线逐段点亮、内容落入槽位、无法修改的反馈、交付物装入文件夹 | 至少 20% |

跨镜承接要留下同一个可辨认的对象。前镜停在路线图的“锁母版”，后镜直接选中对应模板。三维拆页后切入真实文件的文本框边界，保持页面方向、选中对象和画面重心一致。边界演示换另一张真实页面，并检查字幕和作者栏的位置。

用 `kit/scripts/build-spatial-block.sh --spec block.json --output blocks/scene` 生成原生离线子合成。在分镜中使用 `stage_mode: hyperframes_block` 和 `composition: blocks/scene/index.html`。每个配置包含唯一 `id`、秒数 `duration`、配方 `recipe` 和 `data`。图片路径相对于配置文件。可选 `title`、`eyebrow` 和六位色值 `accent`。

- `carousel_3d_select` 接受 5–12 张本地 `images`、从 0 起的 `selected_index` 和抽选时点 `select_at`。
- `layer_explode_3d` 接受实际页面 `image`、可选的无文字底层 `background_image`、相对画布的 `boxes: [[x,y,w,h], …]`、真实的 `count` 和 `unit`。
- `roadmap_thread_camera` 接受 3–4 个 `steps`，各项含 `no/title/sub/at`，以及从 0 起的 `focus_step`。
- `literal_action_stage` 通过 `action` 选择 `bad_slides_pileup`（三项 labels 与 warning）、`dead_image_locked`（image 与 warning）、`slot_lock_fill`（三到四项 labels）或 `folder_pack_outro`（images、folder 与 command）。

在最终像素上检查动作。为环绕、推镜、分层各导出早中晚三帧，再执行 `audit-v3.sh --v10`。门禁按镜长计算三态的比例，空间合成必须有独立图层的实际运动；贴图数量和分镜自报形态不能代替动效证据。

### 本机 Skill 协同表

| 制片时机 | 使用的能力 | 看什么结果 |
|---|---|---|
| 选钩子与定稿 | hyperframes-creative 的 story-spine、beat-direction；humanizer-zh；cheat-score | 先给观众能得到的结果，再给可溯源证据。口播去掉空泛宣传、机械转折和三段排比。用项目 rubric 核对首句的具体收益和兑现方式。 |
| 搭建三维合成 | hyperframes-animation 的 22 套蓝图、48 条规则；hyperframes-registry 的颗粒与环境光 | 环绕用 orbit-3d-entry、constellation-hub；分层用 3d-camera-flight、depth-of-field-blur、counting-dynamic-scale；路线用 spatial-pan-stations、svg-path-draw 与 spring-pop-entrance。相机只写 world 的单一变换，景深落在叶子上。 |
| 物件触碰、跨拍交接与收束 | onetake 的 lib/motion.js、lib/ui_kit.js；参考 skill-demo-15s、onetake-launch-30s | 用 camera/view 驱动相机、lattice 表现视差；用 gather、seal 和弹簧让上一拍实物进入下一拍。用 180° 快门采样导出。 |
| 动作验证 | HyperFrames check 和 animation-map | 检视早中晚实际像素、回跳定位和每拍有效运动。 |

用 `python3 kit/scripts/audit_spatial.py blocks/scene/index.html --out motion.json` 在本机无头浏览器里枚举全部 tween、抽取等距六点、回跳复验。报告保留每段实际发生位移、形变、显隐或内容变化的元素数及对应时间窗。每个空间块也要通过 HyperFrames check。
