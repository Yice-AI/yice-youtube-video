# 高留存叙事与三态画面（v17.0）

口播先按[散文母稿与长视频四条母法](03-散文母稿与长视频四条母法.md)写成 `narration.md` 并拆成 `script.md`，本篇管拆表后的节奏与镜头。**严禁虚构脱离大众的假场景、严禁报幕吊胃口、严禁大模型和稀泥叠甲腔**：
1. **前 10 秒真事反差 + 砸预期摆抽屉（禁客服报菜名）**：拒绝像软件导购员一样上来罗列“今天介绍 5 个工具”。第一秒必须抛出**亲身撞见的反常识真事、残酷对照实验或切身痛感**（如“熬三个通宵剪的片，流量不如别人十句大白话出的图”），前 10 秒再用 `triptych_curtain` 或 `chapter_drawer_grid` 在观众脑子里摆好 3–6 个清晰抽屉；每次进新章可用 `chapter_drawer_grid`（设 `active_index`）拉开对应抽屉防迷路。
2. **单模块固定三拍 + 2 分钟防走神排序**：每个工具固定走「① 一句大白话定死干嘛的 → ② 真实干活体感与默认/加词前后反差（`prompt_iter_workbench`）→ ③ **直说一个真毛病或协议边界**（敢说缺点才像活人）」。多工具出场顺序按：**前两位放硬核实力派垫实干货 → 播到 2 分多钟易走神处放最具反差/当下最热风口把注意力拽回来 → 最后落到零门槛免费立即可用的工具收尾**。
3. **改稿守卫（`precheck --stage script` 硬拦）**：口播像真人面对面讲，长短句自然交替，允许通俗生活类比和清楚的对比句；删光没有结论、没有例子、没有具体做法的铺垫句；严禁“见仁见智、因人而异”等两边不得罪叠甲词（`llm_hedging_fluff`）与“神器、全网最强、效率提升 300%”等无依据吹牛词（`unverified_hype_claim`）；英文或专业词当场说它干什么；单段不堆冷冰冰小数（`decimal_overload`），换成“省一半、成本六分之一、十题对八题”。
4. **片尾截屏速查表拉收藏**：结尾用 `saveable_cheat_sheet` 把整期各抽屉浓缩成一张「工具/模块 × 一句话提示词 × 避坑边界」高清一页总表（带 `✦ 截屏保存` 胶囊）停稳 4 秒，直接拉升收藏率与完播率。

## 剧本三条硬规矩（`precheck-episode.sh --stage script` 把关）

1. **画面列由母稿拆出。** `script.md` 由 `kit/scripts/split-narration.sh narration.md` 生成，幕表格为 `| 幕号 | 旁白 | 画面 |` 三列，母稿里的 `〔画面：…〕` / `〔演示：…〕` 一字不改落入第 3 列；拆表后可在第 3 列补镜头配方，旁白列不手改（改了报 `narration_script_out_of_sync`）。
2. **骂丑就放丑。** 旁白出现难看、丑、模板感、翻车、死板、廉价、废片等词，画面列必须写清放哪张真实反例原件或默认直出画面，或在清单里给该幕配 `split_wipe_compare`、`prompt_iter_workbench`、`literal_action_stage` 等对比镜头，否则报 `unpaired_pain_point_visual`。
3. **至少两章给可照抄的提示词。** 三章以上的教程至少两章写出引号里的中文提示词和前后变化（“输入「深色科技新品演示页」，默认直出很平；加上一句「Bento 网格与大字数据卡」立刻有发布会质感”），否则报 `missing_hands_on_prompt_loop`。口播里不念截图等待秒数、临时目录、字段名这类制作端细节（`maker_plumbing_leak`），前两幕不说“大家好我是”，前 60 秒不念命令和路径（`slow_or_meta_opener`）。

| 形态 | 观众看到什么 | 教程时长占比 |
|---|---|---|
| M1 空间合成 | 3D 扇形动态视频墙、多模型 Bento 拼装、剪纸视差剧场、纪录片 2.5D 运镜解剖，或页面骨架与原生文本在深度方向分别移动 | 至少 15% |
| M2 实操 | 真实录屏中的一次输入、点击、修改或导出；讲用法优先提示词迭代台，终端只留安装那一下 | 30%–58% |
| M3 流程动画 | 提示词迭代台、分步生长工作流焦点树、渐进装置对比卡、因果胶囊链、中线扫描/斜切擦除/竞速台、手绘铅笔/Riso 推演，或路线/槽位/交付物理动作 | 至少 20% |

跨镜承接要留下同一个可辨认的对象。前镜停在路线图或工作流树的焦点节点，后镜直接切入对应操作或实拍画面；多卡总览接单卡全屏时，用 `exit_zoom_index` + `exit_zoom_at` 点中目标卡推近撑满 `1920×1080`，不生硬直切。作品展示用影院暗场，切到方法与决策时换成 `swiss_paper`，换底色要与口播换意同时发生。

用 `kit/scripts/build-spatial-block.sh --spec block.json --output blocks/scene` 生成原生离线子合成，或在 `episode-manifest.json` 中直接填写 `spatial_spec`（HyperFrames 空间积木）或 `onetake_spec`（Onetake 连续快门镜）。所有多图/视频卡配方均原生支持 `.mp4 / .webm` 真动态视频贴图。

## 空间积木核心配方（`kit/spatial/`）

- `perspective_video_fan`（M1）：3–6 个动态视频或高清图 `items` 在 3D Y 轴扇形错落排布并滑行，随后焦点卡回正推近，顶部带 `✦ 修改后` 胶囊签；`exit_zoom: true` + `exit_zoom_at` 在镜末把焦点卡推近撑满全屏。
- `logo_bento_stage`（M1）：主品牌 `brand` 与 2–4 组 `modules`（`category`、`at`、`items`）按口播依次弹簧落位，核心标志持续微旋转。
- `cutout_parallax_stage`（M1）：`hero` 透明抠图 + 1–3 张 `props` + 悬挂 `banner` + 翻飞字卡 `tiles` + 实时递增计数器 `counter`，4px 剪纸白边 + 三层视差 + 烟尘粒子（详见 [一手高光素材与代码造画母法](02-一手高光素材与代码造画母法.md)）。
- `documentary_ken_burns`（M1）：1 张 16:9 艺术大图 `image` 配合 `focal_from` → `focal_to` 推摇、金粉微尘、博物馆 `archive_tag`，可选在 `split_at` 平滑拆分为 3 张局部解剖卡 `anatomy_cards`。
- `carousel_3d_select`（M1）：5–12 张本地图片或视频、从 0 起的 `selected_index` 和抽选时点 `select_at`。
- `layer_explode_3d`（M1）：实际页面 `image`、可选底层 `background_image`、相对画布的 `boxes`、真实 `count` 和 `unit`。
- `step_tree_focus`（M3）：`heading` + 2–3 个 `branches`（含 `no`、`title`、`at`、`children`）+ `focus_sequence`（随口播在分支间跳转斜纹/霓虹焦点）。
- `prompt_iter_workbench`（M3）：顶部 `prompt_chips`（`{role, text, at}`）逐拍弹出拆解大白话提示词，主画框 `16:9` 零裁边先放 `before_source`（`↺ 默认直出`），到 `iter_at` 换成 `after_source`（`✦ 加词精修后`），`exit_zoom_after` + `exit_zoom_at` 推近成品接下一镜。
- `progressive_sim_cards`（M3）：顶部主题 `heading` + 2–3 张 `cards`；不写 `board` 时在所有 `stage_look` 下首卡居中弹簧跃出、后续卡按 `at` 依次推开落位。支持 `race_bars`（`1% → 26%` 对比 `100%`）与 `live_media`（`.mp4` 真视频），`16:9` 横屏源且 `zoom == 1` 时按原画幅零裁边展示；`exit_zoom_index` + `exit_zoom_at`（默认镜末前 `0.48s`）推近目标卡。
- `formula_pill_chain`（M3）：顶部 `source_pill` 左移并在 `reveal_at` 射出箭头与 `target_pill`，下方画框同步播放真实 `.mp4` 样片。
- `roadmap_thread_camera`（M3）：3–4 个 `steps`（`no/title/sub/at`）与 `focus_step`。
- `literal_action_stage`（M3）：`bad_slides_pileup`、`dead_image_locked`、`slot_lock_fill`、`folder_pack_outro`。

在最终像素上检查动作。为关键镜头导出早中晚三帧并执行 `audit-v3.sh --v10`。门禁按镜长计算三态比例，空间合成必须有独立图层运动；贴图数量和自报形态不能代替动效证据。

### 本机 Skill 协同表

| 制片时机 | 使用的能力 | 看什么结果 |
|---|---|---|
| 选钩子与定稿 | `precheck-episode.sh --stage packaging/script`；hyperframes-creative 的 story-spine、beat-direction；humanizer-zh；cheat-score | 先给观众能得到的结果，再给可溯源证据。口播去掉空泛宣传、机械转折和三段排比。 |
| 搭建三维合成与造画 | hyperframes-animation 的 22 套蓝图、48 条规则；`image2` + `cutout.sh`；`kit/spatial/` 14 套配方 | 环绕/视频墙/视差/文物推镜用 M1 配方；提示词迭代台/分支树/渐进卡/胶囊链用 M3 配方。 |
| 物件触碰、对比擦除与手绘 | onetake 的 lib/motion.js、lib/ui_kit.js、`sketch_brush.js`；`split_wipe_compare`、`handdrawn_sketch_stage` | 用 `camera`/`view`/`spring` 驱动物理反应与视频帧序列切帧，180° 快门采样导出。 |
| 动作与调性验证 | HyperFrames `check` 与 `audit-v3.sh --v10` | 检视早中晚实际像素、回跳定位、零文字遮挡、作品暗场与方法亮场的交接。 |

用 `python3 kit/scripts/audit_spatial.py blocks/scene/index.html --out motion.json` 在本机无头浏览器里枚举全部 tween、抽取等距六点、回跳复验。每个空间块也要通过 HyperFrames `check`。

影院暗场展示成品和对比，瑞士亮场承接分类与方法。主脑交片前关字幕、有声连看全章。逐项确认反例与真实操作看得懂、口播数量与同屏成品一致、没有连续三秒的死镜、前六十秒不出现终端、字幕带不压核心文字、每种声音都对应可见动作。 [交片审计](review-gates.md)
