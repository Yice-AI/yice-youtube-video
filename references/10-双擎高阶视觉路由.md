# v12.0 双擎高阶视觉路由

## 一、双调性母版与三类王牌画面路由

v12.0 将高留存视觉浓缩为「**双整片母版 + 三类画面配方**」，旧版单场清单沿用一种母版，v14 允许随叙事在影院展示与 `swiss_paper` 方法画布间切换（严禁无故中途乱跳底色）：

| 母版名 | 适用题材 | 主控背景与字幕 |
| --- | --- | --- |
| `cyber_glass`（暗黑玻璃） | AI 工具实操、代码工程、模型对比、终端工作台 | `luma <= 42` 暗黑玻璃 + 霓虹/珊瑚红强调，净片白字字幕 |
| `editorial_paper` / `scroll_paper`（暖米白画布） | 深度方法论、工作流拆解、古画/科普叙事、手绘动画 | `luma >= 185`（古卷 `scroll_paper` `>= 115`）+ 墨黑高对比字 + 自动切换 `caption-on-light` 深色胶囊字幕 |

| 画面类型 | 对标场景 | 首选引擎与配方 |
| --- | --- | --- |
| **第 1 类：素材×贴图×立体空间复合** | 改后成品视频墙、多工具全家桶、双栏/斜切/竞速对比、剪纸视差、古画 2.5D 推摇拆卡 | HyperFrames：`perspective_video_fan`、`logo_bento_stage`、`cutout_parallax_stage`、`documentary_ken_burns`、`carousel_3d_select`、`layer_explode_3d`<br>Onetake：`split_wipe_compare`（`center_scan` / `diagonal_wipe` / `quad_race`） |
| **第 2 类：满屏真实操作实录** | 命令安装、提示词输入、网页交互成品点击、边界验证 | `fullbleed_rig` / `callout_rig` + `focus_push` / `camera_moves`（占教程实录 ≥ 70%） |
| **第 3 类：纯贴图/纯代码流程推演** | 分步工作流焦点切换、1% vs 100% 渐进卡、因果胶囊链、8fps 手绘铅笔水彩 / Riso 半调 | HyperFrames：`step_tree_focus`、`progressive_sim_cards`、`formula_pill_chain`、`roadmap_thread_camera`<br>Onetake：`handdrawn_sketch_stage`、`duplicate_laser_sweep`、`live_control_sync`、`capsule_archive_seal` |

## 二、双擎 `.mp4 / .webm` 真动态视频贴图规范

- **HyperFrames 空间积木（`kit/spatial/block.py`）**：`perspective_video_fan`、`progressive_sim_cards`、`formula_pill_chain`、`carousel_3d_select` 等所有媒体槽位直接传入 `.mp4 / .webm`。构建器自动生成带合成唯一 `id` 与 `data-start="0" data-duration="{dur}"` 的 `<video>`；离线采样器 `sample-spatial-frames.cjs` 采样前同步 `currentTime` 并等待 `seeked`，彻底杜绝黑框。
- **Onetake 确定性帧序列（`kit/onetake/scene.py`）**：当 `split_wipe_compare` 等配方接收 `.mp4 / .webm` 时，构建期自动调用 `ffmpeg` 按 `24fps`（限长 `min(dur+0.5, 12.0)` 秒、宽度 `≤960px`）预解成 `vframes_<hash>/f_0001.jpg ...`，在 `window.__ready` 前全部预解码并在 `window.__seek(t)` 同步绘制至 `<canvas>`，在 180° 快门模糊下实现丝滑无闪黑的动态视频擦除与竞速！

## 三、Onetake 声明式配方清单（7 套）

```json
{"stage_mode":"onetake_clip","shutter":180,"look":"dusk","onetake_spec":{"recipe":"split_wipe_compare","hud":"BEFORE ↔ AFTER","data":{"mode":"center_scan","before":"media/raw.mp4","after":"media/final.mp4","before_label":"↺ 修改前","after_label":"✦ 修改后"}}}
```

| Onetake 配方 | `data` 核心字段 |
| --- | --- |
| `split_wipe_compare`（v12） | `mode`（`center_scan` \| `diagonal_wipe` \| `quad_race`）、`before`、`after`（均支持 `.mp4/.webm` 或图）、可选 `before_label`、`after_label`、`left_meta`、`right_meta` |
| `handdrawn_sketch_stage`（v12） | `style`（`pencil_watercolor` \| `riso_halftone`）、`title`、`nodes`（2–4 项 `{title, sub, at, icon?, color?}`）、可选 `monster`（bool）、`gauge`（`{label, from, to}`） |
| `duplicate_laser_sweep` | `cards`（三个标题）、`series`、`caption`、可选 `warning` |
| `bitmap_lock_glitch` | `image`、可选 `warning` |
| `energy_roadmap_dive` | `stations`（3–4 组 `image/label/caption`）、`target`、可选 `dive_image` |
| `live_control_sync` | `image`、`slider`、`switch`、`canvas` |
| `capsule_archive_seal` | `images`（2–6 张）、`project`、`file`、`command` |

## 五、按题材速选与调色检查

```bash
kit/scripts/visual-palette.sh --list-looks
kit/scripts/visual-palette.sh --from-shot product.png --output look.json
kit/scripts/visual-palette.sh --list-blueprints --role Key_Feature
kit/scripts/build-spatial-block.sh --spec block.json --output blocks/scene
kit/scripts/build-onetake-scene.sh --spec scene.json --output preview
```

- 跨镜复用与审片契约、探针机制及 OCR 白名单见 [审片门禁](review-gates.md)。
- 单镜手绘 `handdrawn_sketch_stage` 离线使用 `kit/onetake/sketch_brush.js`；Onetake `render-onetake-clip.py` 默认使用 2 个低优先级进程与 180° 快门积分。
