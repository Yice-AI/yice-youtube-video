# v10.0 双擎高阶视觉路由

## 按题材选色板与动效

以内容、可读性和画面质量决定风格。同一皮肤可以服务多段叙事。需要体现真实产品品牌时，从 1–3 张截图提取八色，再搭配叙事动作。

| 题材 | 色板 | 动效入口 |
| --- | --- | --- |
| 商业增长、数据复盘 | `ultramarine` | HyperFrames `dataviz-countup`、数字滚轮、曲线读数 |
| 产品交互、工具教学 | `paper` 或截图吸色 | `cursor-ui-demo`、`prompt-type-submit-generate`、Onetake `press` 和 `morphRect` |
| 深度观点、品牌叙事 | `ember` 或 `dusk` | Onetake `lightField`、`ripple` 和 `wordRise`，或 HyperFrames 运镜蓝图 |
| 实物演练、印刷设计 | `tabletop` 或 `riso` | 接触回弹、平面材料和高光擦拭 |

`visual-palette.sh` 读取本机参考，列表模式输出到标准输出（可加 `--json > out.json` 重定向保存），截图取色模式用 `--output look.json` 落盘。可检索 22 套 HyperFrames 动态分镜蓝图、原子动效索引（基线 47 条，实际随本机版本更新）、39 种 Onetake 原语、转场目录和约 400 个 Registry 组件。

```bash
kit/scripts/visual-palette.sh --list-looks
kit/scripts/visual-palette.sh --from-shot product.png --output look.json
kit/scripts/visual-palette.sh --list-blueprints --role Key_Feature
kit/scripts/visual-palette.sh --list-rules
kit/scripts/visual-palette.sh --list-onetake-moves
kit/scripts/visual-palette.sh --list-transitions
kit/scripts/visual-palette.sh --search-registry "vertical rolling number"
```

## Onetake 关键镜头

机制高潮或片尾需要单主体连续变形时选这一路。让同一个视觉对象随口播发生变化，例如剪辑轨道中的扫描游标带观众拉出到光学取景器。用 `OM.wordRise`、`OM.morphRect`、`OM.camera` 或 `OM.zoomThrough` 连续调度。三张纯文本方框的硬切无法承担这类镜头。

```json
{"stage_mode":"onetake_clip","comp":"motion/opening/comp.html","shutter":180}
```

合成目录自带所需本地素材。两张及以上图片并列时必须有独立空间运动，并以 v10 逐镜核验。2–4 项对照使用 `triptych_cards`，档案使用 `y2_vox` 暖纸冲印，刻度和图表使用 `t5_data_ruler` 或 `t3_finance_chart`，终端使用 `studio_ui`。页面提供无状态的 `window.__seek(t)`、`window.__ready` 和 `window.__meta={dur,fps:30}`。可加 `__meta.beats`、`__motion(t0,t1)`、`__track(t)` 和返回 `[{t,kind,gain?}]` 的 `__events()`。所有时间为镜内相对秒。在 `document.fonts.ready` 之后完成首帧，字重分别用 `Source Han Sans CN` 700、`Source Han Serif CN` 900、`Source Code Pro` 400。桥接器在隔离目录提供字体、`window.OM` 和本机存在的 UI kit。

用 `"look":"paper"` 或 `"look_from_shots":["product.png"]` 启用 `window.LOOK` 和 `look-tokens.css`。HTML 可以直接读 `var(--ground)`、`var(--accent)` 等八色及字体变量，Canvas 用 `LOOK.font()`，合成就绪可等待 `LOOK.ready`。装配器把色板和截图指纹记入渲染缓存。

先探针后渲染。所有跨拍边界都为 `bare` 时会拦截。明确设计为断奏时可在单镜使用 `allow_staccato: true`。片段旁生成 `.onetake-probe.json`、`.render.json` 和装配缓存指纹，音效事件随镜头入点进入混音时间轴。单镜默认使用两个低优先级渲染进程。装片用 --draft 试片，正式输出自动区分画质缓存。

```bash
kit/scripts/render-onetake-clip.sh motion/opening/comp.html --out out/opening.mp4 --span 3.2 --shutter 180
```

`install.sh --check` 报告可选的 `onetake_ready`。设 `YICE_ONETAKE_DIR` 指定本机安装。有独立 Python 或离线环境时，可用 `YICE_ONETAKE_PYTHON` 指定命令。该环境需要 Playwright、本机 Chromium、NumPy 和 Pillow。

## HyperFrames 动态机制

多阶段架构、3D 卡片阵列和交互状态推演使用 `hyperframes_block`。先在 HyperFrames Registry 的 400+ 组件或 HyperFrames Animation 的 22 套蓝图里选匹配的机制，再把节点点亮、物体运动和路径转移对到实际口播。样式、媒体和独立 JS 都放在子合成目录。子合成的根 `data-composition-id` 必须与 `window.__timelines` 注册键一致，使用单条暂停的 GSAP 时间轴。原生挂载用 `<template>` 包住样式、根节点和脚本。依赖使用本地文件，装配器提供 `vendor/gsap.min.js` 与 `assets/fonts/`。

```json
{"stage_mode":"hyperframes_block","composition":"blocks/architecture/index.html",
 "transition_in":{"kind":"zoom_through","duration":0.4}}
```

## 实录窗与听觉衔接

工具教程先录官方复杂成品、输入与执行、成品交互。满屏跟焦至少占实录时长 70%，斜框至多占全片时长 15%，带框镜头不能相邻。`callout_rig` 或 `fullbleed_rig` 可用 `framing: "perspective_3d"` 让视频、浏览器外框与已核对高亮共用 3D 姿态。`studio_window` 提供平面浮窗。`obsidian`、`aurora_indigo` 或 `atmosphere: "cinema_glow"` 加入环境光、细颗粒，并在视窗上加入细边折射和一次扫光。

`prop_badge` 和 `reaction_cutout` 使用 `placement: "foreground_hero"` 可在 `left` 或 `right` 放置 340–460 px 的破框贴图。把主视觉留在 `y ≤ 885`，中央底部留给字幕。同幕第二镜起可声明 `whip_push`、`zoom_through`、`iris_reveal` 或 `blur_crossfade`。当前镜与前镜的视觉动画从同一切点开始，逻辑切点、旁白与字幕时间继续使用原时间轴。

`triptych_cards` 选现代主题即可使用暗色或暖浅色的圆角展台。贴图进镜前，用 `scout-video-scenes.sh --verify-manifest` 查看贴图可见期间的首、中、尾 OCR 命中和核验图。确认前景主体完整，并把贴图避开底层视频的有效文字。

`t7_editorial_board` 用于维持旧项目。新片尾按口播选一个视觉主体做连续收束。交付前检查实际渲染的文字、转场中间帧和快门瞬态，并运行 `audit-v3.sh --v10`。
