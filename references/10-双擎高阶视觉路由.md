# v15.0 双擎高阶视觉路由

## 一、双调性母版与三类王牌画面路由

v15.0 将高留存视觉浓缩为「**作品暗场、逻辑亮场与三类画面配方**」，旧版单场清单沿用一种母版，v15 允许随叙事在影院展示与 `swiss_paper` 方法画布间切换（严禁无故中途乱跳底色）：

| 母版名 | 适用题材 | 主控背景与字幕 |
| --- | --- | --- |
| `cyber_glass`（暗黑玻璃） | AI 工具实操、代码工程、模型对比、终端工作台 | `luma <= 42` 暗黑玻璃 + 霓虹/珊瑚红强调，净片白字字幕 |
| `editorial_paper` / `scroll_paper`（暖米白画布） | 深度方法论、工作流拆解、古画/科普叙事、手绘动画 | `luma >= 185`（古卷 `scroll_paper` `>= 115`）+ 墨黑高对比字 + 自动切换 `caption-on-light` 深色胶囊字幕 |

| 画面类型 | 对标场景 | 首选引擎与配方 |
| --- | --- | --- |
| **第 1 类：素材×贴图×立体空间复合** | 改后成品视频墙、多工具全家桶、双栏/斜切/竞速对比、剪纸视差、古画 2.5D 推摇拆卡 | HyperFrames：`perspective_video_fan`、`logo_bento_stage`、`cutout_parallax_stage`、`documentary_ken_burns`、`carousel_3d_select`、`layer_explode_3d`<br>Onetake：`split_wipe_compare`（`center_scan` / `diagonal_wipe` / `quad_race`） |
| **第 2 类：满屏真实操作实录** | 命令安装、提示词输入、网页交互成品点击、边界验证 | `fullbleed_rig` / `callout_rig` + `focus_push` / `camera_moves`（占教程实录 ≥ 70%） |
| **第 3 类：纯贴图/纯代码流程推演** | 提示词拆解与前后迭代、分步工作流焦点切换、1% vs 100% 渐进卡、因果胶囊链、8fps 手绘铅笔水彩 / Riso 半调 | HyperFrames：`prompt_iter_workbench`、`step_tree_focus`、`progressive_sim_cards`、`formula_pill_chain`、`roadmap_thread_camera`<br>Onetake：`handdrawn_sketch_stage`、`duplicate_laser_sweep`、`live_control_sync`、`capsule_archive_seal` |

## 二、双擎 `.mp4 / .webm` 真动态视频贴图规范

- **HyperFrames 空间积木（`kit/spatial/block.py`）**：`perspective_video_fan`、`progressive_sim_cards`、`formula_pill_chain`、`carousel_3d_select` 等所有媒体槽位直接传入 `.mp4 / .webm`。构建器自动生成带合成唯一 `id` 与 `data-start="0" data-duration="{dur}"` 的 `<video>`；离线采样器 `sample-spatial-frames.cjs` 采样前同步 `currentTime` 并等待 `seeked`，彻底杜绝黑框。
- **Onetake 确定性帧序列（`kit/onetake/scene.py`）**：当 `split_wipe_compare` 等配方接收 `.mp4 / .webm` 时，构建期自动调用 `ffmpeg` 按 `24fps`（限长 `min(dur+0.5, 12.0)` 秒、宽度 `≤960px`）预解成 `vframes_<hash>/f_0001.jpg ...`，在 `window.__ready` 前全部预解码并在 `window.__seek(t)` 同步绘制至 `<canvas>`，在 180° 快门模糊下实现丝滑无闪黑的动态视频擦除与竞速！

## 五、多卡、画幅与跨镜衔接

- **全母版弹簧进场**：`progressive_sim_cards` 不写 `board` 时，在 `swiss_paper`、`editorial_paper`、`cyber_glass` 等所有 `stage_look` 下都是首卡居中弹出、后续卡依次推开落位。`board` 开关（三框自开场全在位）只留给确需静态对照的个别镜头，不作默认。
- **横屏与竖版双端零裁边**：`16:9` 横屏 PPT/网页（`zoom == 1`）与 `3:4` 小红书竖图/`9:16` 竖屏均按各自原画幅完整展示：严禁把横屏塞进窄竖框切左右，也严禁用 `16:9` 横屏浏览器截半录 `3:4` 竖图（`portrait_aspect_integrity_gate` 与 `aspect_crop_integrity_gate` 双重硬拦截）。要看局部，显式写 `zoom > 1.05` 与 `focus_x/focus_y`。
- **点中推近接全屏**：多卡总览下一镜接某张卡的全屏实操或成品时，填 `exit_zoom_index` 与可选 `exit_zoom_at`；`perspective_video_fan` 填 `exit_zoom: true`；`prompt_iter_workbench` 填 `exit_zoom_after: true`。组装时在推近点自动配点击加推拉音效。

```json
{"stage_mode":"hyperframes_block","spatial_spec":{"recipe":"progressive_sim_cards","data":{"heading":"三个体感优势","cards":[{"title":"审美拉满","source":"media/a.mp4","at":0.2},{"title":"原件能改","source":"media/b.mp4","at":1.0},{"title":"一稿全出","source":"media/c.mp4","at":1.8}],"exit_zoom_index":1}}}
```
