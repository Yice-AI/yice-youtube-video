# 一手高光素材与代码造画母法（v12.0）

本篇定义**告别“卡片里放死截图”**与**纯代码美术造画**的三大工业级母法，全部配方已内建于 `kit/spatial/` 与 `kit/onetake/`，通过 `episode-manifest.json` 的 `spatial_spec` / `onetake_spec` 直编渲染。

---

## 一、一手高光原片猎手与双擎 `.mp4 / .webm` 真动态视频贴图母法

先用 `kit/scripts/harvest-showcase-media.sh --urls <github.io或官网URL> --output pool --rank-highlights` 无损抓取学术论文项目页（`*.github.io`）、官方发布页或公开实机演示中的原生高清 `<video>` 流（非 16:9 画幅自动合成 `blur_dark` 同源高斯模糊暗底，按运动能量与细节密度自动切出 4.5s 黄金高光并生成候选图墙 `showcase-candidates.jpg`），再直接喂入以下双擎动态贴图管线：

| 引擎 | 视频贴图机制 | 核心收益 |
| --- | --- | --- |
| **HyperFrames (`kit/spatial/block.py`)** | `media_asset()` + `media_tag()` 原生接收 `.mp4/.webm`，自动分配合成唯一 `id` 与 `data-start="0" data-duration="{dur}"`；`sample-spatial-frames.cjs` 采样前自动 seek 并等待 `seeked` | 多卡片 3D 扇形视频墙、装置对照卡、因果胶囊链内部直接播放真视频，彻底消灭黑框与死截图 |
| **Onetake (`kit/onetake/scene.py`)** | 构建期自动调用 `ffmpeg` 按 `24fps`（限长 `min(dur+0.5, 12.0)` 秒、宽度 `≤960px`）预解确定性 JPEG 帧序列 `vframes_<hash>/f_0001.jpg ...`，在 `window.__ready` 前全量 `decode()`，在 `window.__seek(t)` 同步按 `Math.floor(t * fps)` 切帧绘图 | 在 180° 真实快门模糊下，运动/擦除/竞速卡片内部同时丝滑播放真动态视频，零异步闪黑 |

## 二、代码造画三公式（`image2` + 抠图视差 + 2.5D 纪录片 + 手绘笔刷）

### 公式 1：`cutout_parallax_stage`（剪纸白边视差剧场，对标《唐·驿马》）

1. **生成干净独立白底素材**：用 `image2.py` 生成纯 `#FFFFFF` 白底的单一主体（例如古风驿马信使、青绿古松、朱红驿亭），要求主体完整且四边留白。
2. **本地无损抠图**：用 `kit/scripts/cutout.sh`（macOS Vision）分离出透明背景 `transparent.png`。`block.py` 会自动裁去外圈多余透明留白。
3. **三层视差合成**：填入 `spatial_spec`（`recipe: "cutout_parallax_stage"`）：
   - `hero`：主角色透明 PNG（自动裹 4px 奶油剪纸白边 + 柔和纸张投影 + 正弦奔跑起伏 + Canvas 烟尘圆圈）；
   - `props`：1–3 张前景/中景透明道具 PNG，随镜推进错速移动；
   - `banner`：`{"title": "...", "sub": "..."}` 悬挂红线铭牌；
   - `tiles`：逐字翻飞的字卡数组；
   - `counter`：`{"prefix": "已行", "start": 120, "end": 210, "unit": "里", "sub": "..."}` 撕纸实时计数器；
   - `stage_look`：默认 `"scroll_paper"`（宣纸肌理 + 藏青金菱锦缎边 + 远山水墨），可选 `"cyber_glass"`。

### 公式 2：`documentary_ken_burns`（纪录片 2.5D 推摇 + 一图拆三卡解剖，对标《敦煌反弹琵琶》）

1. **生成高精度 16:9 满幅艺术大图**：用 `image2.py` 生成零文字、零现代边框的高密度图像（如矿物岩彩壁画、历史手稿、建筑剖面）。
2. **填入 `spatial_spec`**（`recipe: "documentary_ken_burns"`）：
   - `image`：大图路径；
   - `focal_from` / `focal_to`：`[x, y, scale]` 归一化局部焦点推摇坐标；
   - `archive_tag`：`{"eyebrow": "第 112 窟 · 中唐", "title": "反弹琵琶"}` 博物馆角标；
   - `formula`：可选顶部编辑部单行公式条（`{"label": "...", "key": "风格：", "highlight": "..."}`）；
   - `split_at` + `anatomy_cards`（3 项 `{crop:[x,y,w,h], label, sub}`）：后半段自动从同一张大图裁出 3 张高细节竖卡并排解剖，内置确定性 Canvas 金粉微尘漂浮光斑。

### 公式 3：`handdrawn_sketch_stage`（纯代码 8fps 微抖铅笔水彩与 Riso 半调）

无需外部图片，由 `kit/onetake/sketch_brush.js`（确定性 PRNG `seed + Math.floor(t * 8)`）离线驱动：
- `style: "pencil_watercolor"`：暖米白画纸网格 + 多道抖线铅笔描边 + 羽化水彩色块 + 可选程序化小怪兽与进度液位计；
- `style: "riso_halftone"`：深靛蓝画底 + 荧光粉/湖蓝/明黄周期半调圆点波纹 + 高对比矢量框线；
- 配合 `nodes`（2–4 步节点）与 `OM.camera` 连续推镜，任意回跳 `window.__seek(t)` 100% 一致。

## 三、整片统一双调性母版

| 母版名 | 适用题材 | 边缘背景亮度铁律 | 字幕自动适配 |
| --- | --- | --- | --- |
| `cyber_glass` | AI 工具实操、代码架构、深度科技 | `luma <= 42` | 深底白字净片字幕 |
| `editorial_paper` | 观点分享、工作流拆解、人文科普、设计教程 | `luma >= 185`（`scroll_paper` 允许锦缎土坡 `luma >= 115`） | `assemble-episode.py` 自动切 `caption-on-light` 烟熏深色胶囊 |

> **禁跳底色铁律**：一部片子选定 `cyber_glass` 或 `editorial_paper` 后必须贯穿全片，`audit_spatial.py` 会拦截中途无故乱跳底色（`inconsistent_stage_tone`）。
