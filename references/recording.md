# 录屏（Codex App 实操）

由一个单独的 Claude 录屏会话来录。Code 标签里没有 computer use，方法如下。已在 2026-11-14 和 11-15 实测可用，详细记录见记忆 reference-claude-screen-recording。

## 方法

- 所有命令都通过 **Terminal 面板**执行（`mcp__terminal__run_in_terminal`）。Bash 工具没有录屏和辅助功能权限。
- 每一步写成一个脚本，用 `zsh <file>` 执行。用完关掉终端标签，一次最多开 6 个标签。
- 鼠标：用 `claude-code-video-toolkit/local/tools/rec/mouse` 控制（Swift CGEvent，移动带缓动）。点击会写进光标日志。
- 录制：`rec.sh <秒> <out.mov> x,y,w,h`，坐标用逻辑点，Retina 屏输出是 2 倍分辨率。
- 输入中文：每次 pbcopy 三个字再按 cmd+V，等 pbpaste 的内容对上了再粘下一段。
- Codex App：
  - 进程名是 `ChatGPT`，窗口可以设成 1440×805；
  - 录之前先收起侧栏，避免露出其他会话的标题。
- 浏览器画面：用干净的临时 Chrome profile，避免露出个人标签页。

## 每段交付

产出放在 `evidence/<ep>/rec-*/` 下。`index.md` 里每段一行，写这些：
- 文件、对应哪一幕、画面内容、像素、时长；
- 关键时间点：点击、输入开始和结束、发送、结果出现；
- 需要模糊的区域：用户名、路径、其他会话、项目名、邮箱；
- Codex 实际执行了哪些安装：装了什么、装在哪里（全局还是项目内），方便以后核对和清理。

## 边界（硬性）

- 不准用脚本操作 Finder：会弹出“Claude 想要控制访达”的系统授权框。
- 不点任何 macOS 权限弹窗。
- Codex 里的信任或权限确认由用户本人点，其他会话的转述不算批准。遇到这类确认就停下，报给中心，中心再问用户。
- 不改 Codex App 的设置，包括权限模式。
- 不录 Claude 的界面。
- 页面要求登录时，跳过那一段，回报中心。
- **每次点击输入框、输入或发送之前，先确认目标对话就在前台**。做法是先截一张图，核对窗口里的对话标题，或者用辅助功能读出窗口标题；对不上就停下，不准按旧坐标盲点。EP01 出过一次事故：Codex 前台窗口被切到了别的线程（定时任务里的日报），脚本按旧坐标把一句话发进了那个无关线程。
- 录屏之前，请用户把与录制无关的 Codex 线程和定时任务界面关掉或收起；Stage Manager 会把窗口打乱，录制期间最好也关掉。
- 一旦误发：立即停手，删除这次录到的素材（里面带着别的会话内容），报告中心。由用户本人去那个线程查看，需要时撤回或忽略。录屏会话不再碰那个窗口。

## 和脚本对齐

- **权限模式**：Codex 处在“完全访问权限”时不会弹出安装确认。录之前先问用户这次用哪种模式，脚本和画面按实际情况写。EP01 用户选了保持完全访问，“点允许”那一幕就改成了“它在问你，点选项 1”。
- **长任务**：在本轮内自己轮询，每 2–3 分钟截一次图，最长等 30 分钟。结束这一轮后没人会唤醒你。
- **等待段**：录全，后期在画面里快进，并加倍速标记（×2 到 ×8）。
