# 拆解参考片：拆到能一比一重建

用户给出新样片，或者说“想要某某频道那种感觉”时，用这里的方法。

**标准只有一条：拆完的规格，要能让一个没看过原片的人照着做出一样的幕。** 做不到，就说明还没拆细。

## 为什么必须细（EP01 的教训）

拆参考片 #7 用了好几轮，每一轮都因为不够细被用户退回：

1. **第一轮只拆了切点和运动**（镜头时长、推拉速度）。做出来的东西“不难看但廉价”。
2. **补材质**（T46）：纸边、白边像素、阴影衰减、倾角分布、纹理强度。贴图开始有质感，但仍然“死板”。
3. **补工艺**（T55）：信息卡版式、手写标注的笔宽和速度、印章、绳。
4. **最后才发现组合编排没拆**。用户原话：“贴图先出来，然后左边一个素材图片，右边动效出来一个好看的文字，下方什么的，组合起来很好看。”一幕里几个元素谁先出、隔几帧、从哪来、怎么配合，这一层原来是空白。

所以下面八种拆解卡**一种都不能少**，**组合编排卡最重要**。

## 精度口径

- 以源片帧为单位（30fps 记帧号）。时间写帧数，位置和尺寸写 1920×1080 下的像素，颜色写色值。
- 能测的一律实测：ffmpeg 抽逐帧 PNG，用脚本量像素、颜色、亮度差。不准目测估。量不出来的写“不可反演”，不准编。
- 同类样本至少 5 个，报 P10 / P50 / P90，不只报一个值。
- 每个结论都要附证据：源帧号，加一张不缩放的原尺寸裁切。
- 覆盖面分两类：
  - **普查**：全片每一幕记版式和物件类型，用来统计频率；
  - **精拆**：选 12 个以上典型片段，覆盖钩子、章节头、讲解、证据、对比、否定、结论，逐帧细拆。

## 八种拆解卡（每张卡的必填项）

### ① 组合编排卡（每个精拆片段一张，最重要）

一幕之内，按时间列出每个元素：

| 元素 | 槽位（A 物件 / B 主文字 / C 结构 / D 标注 / E 小字） | 首帧 | 到位帧 | 入场方式 | 起点 → 终点位置 | 缓动 | 和上一元素间隔（帧） | 对哪个旁白词 | 层级（z） | 退场方式 |
|---|---|---|---|---|---|---|---|---|---|---|

另外还要拆这几项：
- **版式**：各元素的位置关系（左图右字、字压图……），对齐用的共享边线或基线，主体占画面的比例，留白在哪。
- **镜头**：入场完成后的持续动作，例如推近到哪、平移多少像素。
- **出下一幕**：靠什么转场，交接的是哪个元素。
- **证据**：这一幕的 16 格逐帧图墙，元素首帧要标出来。

### ② 贴图 / 物件卡（每类物件一张）

- 类型（照片、剪报、文件页、实物、纸签、证件……）及其出现频率；
- 边缘：白边上、下、左、右各多少像素；撕边、切边还是圆角；
- 阴影：分接触影和悬浮影，写方向、离边距离、衰减宽度、比背景暗多少；
- 材质：纸纹或噪点强度（σHF）、饱和度、灰阶处理、颗粒；
- 倾角分布：P10 / P50 / P90；
- 叠放：几层、谁压谁、多少出画；
- 放大到 100% 裁切后的质量：边缘有没有锯齿、抠图有没有残留、光照方向是否一致；
- 来源判断：实拍、档案、生成，还是截图再加工。

### ③ 文字动效卡（每种文字出现方式一张）

- 字体、字号、字重、字距、行高、颜色；
- 动效类型：逐字写入、整组淡入、打字机、遮罩擦出、缩放弹入……，能对上就写 hyperframes-animation 里 24 种文字特效的名称；
- 逐字间隔（帧）、整句时长、缓动、有没有过冲回弹；
- 和旁白的对位：提前还是滞后几帧；
- 写完之后：静止、加荧光、下划线，还是被划掉。

### ④ 特效卡（每种特效一张）

适用于光扫、推拉、虚化、颗粒、闪白、撕纸、翻页、计数滚动、遮罩揭示等。

- 触发时机和持续帧数；
- 参数：强度、范围、方向，模糊半径、亮度变化；
- 缓动曲线：用逐帧位移拟合，写候选曲线（如 easeInOutCubic）和拟合误差；
- 叠在哪一层，和哪个元素配合；
- registry 有没有现成组件可以对应（hyperframes-registry）。

### ⑤ 标注卡（荧光、圈、线、箭头、章、绳）

- 颜色值、笔宽（P10 / P50 / P90）；
- 形状：拟合椭圆的径、起笔收笔、首尾是否闭合、抖动幅度；
- 写入：总帧数、速度（px/s）、中段是否更快；
- 标注加在哪个元素上，比被标注的内容晚几帧出现。

### ⑥ 信息卡卡（台账、表格、清单、时间线）

- 结构类型和出现频率；
- 尺寸和比例；
- 字号分几级、各多少像素；
- 分栏和网格；
- 行是怎么逐条出现的。

### ⑦ 镜头与转场卡

- 镜头时长分布（中位数、每分钟切几次）；
- 硬切比例；
- 每种转场（平移、推进、拿走、匹配剪、叠化）的帧数和缓动；
- 换幕点落在旁白的什么位置。

### ⑧ 声音卡

- 背景音乐：风格、音量相对人声差多少 dB、人声出现时怎么压低、章节切换时怎么变；
- 音效：用在哪些动作上（落下、盖章、划线、翻页），提前几帧，音量；
- 留白：哪些地方完全没有音乐。

## 步骤

1. **粗拆**：`$KIT/scripts/breakdown.sh <视频> <输出目录> [起点秒] [长度秒]`，得到切点统计、每 2 秒帧墙、开头 30 秒逐秒帧。中心看完，选出要精拆的片段，写进 `segment-selection.json`。
2. **逐帧抽取**：
   ```bash
   ffmpeg -ss <起> -t <长> -i 源片 -vsync 0 frames/%06d.png
   ```
   用来拼 16 格图墙，加上原尺寸裁切。
3. **普查加精拆**：派给 Codex（研究角色），按上面八种卡出交付物，测量都要带脚本和原始数据。中心抽查至少 3 张卡，对照源帧核实，不对就退回。
4. **可借鉴清单**：按 A / B / C 三级分。
   - A：直接迁入；
   - B：题目确实需要时才用；
   - C：不迁入。

   每条写明源片位置、适合用在哪、每期增加多少工时。
5. **落地**：
   - A 类手法写成配方：先查 registry，再写进 `kit/template/recipes/_src`；
   - 参数写进 `frame.md` 和 `director-layer.md`；
   - 组合编排卡变成配方里的出场时间表。
6. **对标验收**：每个新配方做一幕金样，和原片的对标帧并排比三次：
   - 整帧对比；
   - 放大到 100% 裁切后对比；
   - 逐帧时间线对比（元素首帧、间隔）。

   三项都像了，才能入库。

## 交付物清单

`overview.md`（结论）、`segments.json`（普查）、`segment-selection.json`，以及八种拆解卡：

- `choreography/`：组合编排卡
- `art/`：贴图、物件、材质
- `text/`：文字动效
- `fx/`：特效
- `craft/`：标注加信息卡
- `transitions.json`：镜头与转场
- `audio.md`：声音

另外还有 `borrow.md`（可借鉴清单）和 `verification.json`（中心抽查记录）。

本机范例：`$YICE_WORKSPACE/.scratch/youtube/research/edit-breakdown/ref7/`（#7 的拆解，不进公开仓库）。其中 `art/treatments.md`、`craft/annotations.md`、`craft/cards.md` 的精度就是标准。

## 注意

- 参考片和拆出来的帧只留在本机，不上传，也不进仓库。
- 学的是手法和参数，不复制别人的画面、角色和品牌。
- 先分清哪部分值得学。#7 是纪录片，它的高级感来自满屏真实档案，极简外壳只是陪衬；我们拍教程，对应的“档案”是真实屏幕。只学外壳，画面就会素。
- HyperFrames 的 `reverse-any-video` 能把一段视频逐帧重建成工程，适合验证某一个镜头的复刻效果，不能替代八种卡。
