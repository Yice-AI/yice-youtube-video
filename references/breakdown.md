# 拆解参考片：把“好看”变成可复刻的规格

用户给出一部新的样片，或者说“想要某某频道那种感觉”时，用这里的方法。EP01 的视觉体系就是这样从参考片 #7 和 Replica39 一路拆出来的。

原则：**一部参考片，六层都拆成可量化、可检查的规格，才算能复刻。** 漏掉哪一层，哪一层就靠临场发挥，质量就会时好时坏。EP01 早期“不难看但廉价”，原因就是 L3、L4 没拆。

## 六层

| 层 | 拆什么 | 交付物（要有原片帧作证据） |
|---|---|---|
| L0 叙事 | 怎么分幕、是否一幕一事、哪类信息配哪种画面、钩子怎么做 | 分幕表：时间、这一幕在讲什么、信息类型、用的手法 |
| L1 运动 | 镜头时长、动画帧数和缓动曲线、动作和旁白怎么对位 | 切点统计（中位镜头时长、每分钟切几次）、典型动作的帧数测量 |
| L2 版式 | 主角的大小和位置、叠几层、多少出画、留白 | 版式原型清单，每种配 2–3 帧 |
| L3 美术材质 | 素材被做成了什么“物件”（打印纸、照片、剪报、实物）、怎么处理（白边、灰阶、颗粒、倾斜、投影）、字体、配色 | 物件目录加出现频率、处理参数、调色板 |
| L4 选材 | 一个意思用什么现实物件来表达；素材从哪来（拍摄、生成、截图、档案） | 意思到物件的对照表、来源分布 |
| L5 工艺 | 卡片排版（分栏、网格、3–4 级字号）、手作标注（墨圈抖动、起笔收笔、印章纹理、绳结）、写入式动画、整幕镜头漂移 | 放大到 100% 的裁切对照图、动画写入过程的帧序列 |

## 步骤

1. **粗拆**（几分钟）：`$KIT/scripts/breakdown.sh <视频> <输出目录> [起点秒] [长度秒]`。输出：
   - 全片切点统计；
   - 窗口内每 2 秒一帧的帧墙；
   - 开头 30 秒逐秒一帧（看钩子）。

   中心先看帧墙，判断值得拆哪几段。
2. **分层细拆**：派给 Codex（拆解角色）按六层逐层出交付物。
   - 测量类：帧数、像素、颜色值，用 ffmpeg 加脚本量出来，不准目测估。
   - 判断类：好在哪、我们能借什么，由中心自己做。
3. **可借鉴清单**：按 A、B、C 三级分。
   - A 类：直接迁入，每期新增成本低；
   - B 类：题目确实需要时再用；
   - C 类：不迁入，例如长插段、大段卡通。

   每条写明：源片位置、适合用在哪、每期新增工时。范例：`borrow.md` 格式。
4. **落地**：
   - A 类手法变成配方：先查 hyperframes-registry 有没有现成组件，再写进 `kit/template/recipes/_src`；
   - 规格写进 `kit/template/frame.md` 和 `references/director-layer.md`。
5. **对标验收**：每个新配方做一幕“金样”，和参考片的对标帧并排比较，整帧比一次，100% 裁切再比一次。不像就退回重做，像了才能入库。

## 注意

- 参考片只读。不上传、不入仓库，帧和测量结果留在本机的 research 目录。
- 学的是手法和规格，不复制别人的画面、角色和品牌。
- 要分清哪部分值得抄：#7 是纪录片，它的高级感来自满屏真实档案，极简的外壳只是陪衬；我们是教程，对应的“档案”是真实屏幕。只抄外壳，画面就会素。
- HyperFrames 也有 `reverse-any-video` skill，可以把一段视频逐帧重建成工程。只在需要精确复刻某个镜头时用；日常拆解用上面的六层法就够了。
