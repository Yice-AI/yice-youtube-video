# 导演层（v2）：逐句判断画面需求 → 当场调用工具生产 → 装入高阶组件

EP03 的核心教训是：如果把生图、生视频、网页抓取、录屏只当成剪辑前的“一次性备料”，到了剪辑时要求执行者“只用已有素材填空”，结果必然是两头翻车——要么反复切回同一段静止界面凑时长，要么让执行者用裸 CSS/SVG 硬画简陋贴纸。

从 v2 起，**剪辑环节本身就是“按句选工具、缺画面当场造、只往高阶组件槽位装内容”的闭环**。输入是 `script.md` + `voice-timing.json`，输出是 `beat-table.md`、`asset-ledger.jsonl` 和 `beats.json`。

---

## 1. 逐句剪辑五步循环（每一句都必须走完）

对 `script.md` 里的每一句（或紧密相连的 2 句，镜头时长 2.0–8.0 秒）：

1. **定视觉锚点词**：找出这句话里**最具体、能被眼睛看见的名词、动作、数字或反差**（如“隔了不到一天”“四百四十八个特效”“挡住了一半”“百分之七十三”）。没有看得见的主体，不准建镜。
2. **查「画面需求 → 工具 → 组件」总表（见第 2 节）**：先定这句话需要哪类画面证据或视觉表达，再锁定对应的生产工具和高阶组件。
3. **盘库或当场生产（`kit/scripts/produce-asset.sh`）**：
   - 查当前项目的素材库：是否有**语义严丝合缝、分辨率达标、且该时间段内画面有真实运动（非静止 >1.8s）**的现成素材？
   - **没有，或者现成素材已经达到复用上限（填充素材每章 ≤2 次、全片 ≤4 次），立刻在剪辑当下调用 `produce-asset.sh` 现场造出来！** 绝不拿泛泛的敲键盘空镜、旧访达窗口或白底文字卡凑数。
4. **套用示范镜头与高阶组件填槽**：
   - 打开 `kit/docs/tool-demos.md` 找到对应工具的标准示范镜头（`D1`–`D7`），直接复用已验证过美感的组件 `recipe + props` 结构，只替换素材路径、实测数字、屏上短关键词和 `@锚点词` 时间。
   - **铁律：严禁自写裸 HTML/CSS/SVG 画小人、画简陋图标或拼贴色块。**
5. **过画幅与运动自检**：
   - 横屏 16:9 素材是否完整展示核心信息（严禁竖裁）？
   - 镜头内是否有持续漂移（`drift`）+ 至少 1 个对准口播锚点的二次动作？

## 3. 高阶组件库与版式铁律（彻底消灭简陋感与裁切感）

### 3.1 统一影棚级质感（Cinema Dark + Studio Craft）
- **主舞台（推荐占 60%–75% 镜头）**：石墨暗调影棚（`#0c0d0e` 底 + 径向顶光 `#1e2126 → #0c0d0e` + 6% 动态胶片颗粒 + 四角 40% 光学暗角），大字与标签统一暖白 `#efe8dc`（思源宋 Bold / 思源黑 Heavy / Source Code Pro），唯一高饱和强调色为朱红 `#ff4a2b`（仅用于印章、焦点直角框、排除划线、播放头与核心差值）。
- **工作台舞台（占 25%–40% 镜头，打破全黑疲劳）**：`paper-cool` 冷白或 `paper-warm` 暖米工作台，必须带左上窗光衰减（九宫格亮度差 ≥20 级）、纸张纤维与双层接触阴影（贴面阴影 + 漂浮柔和投影），绝不用纯白 `#ffffff` 或平涂灰卡。
- **小字标签收敛**：满屏画面统一使用左上角等宽 `.chip` 标签（`64, 56`，24px，半透明深底细边），单镜最多 1 个；关闭冗余的左上大横幅标题，字幕统一走外挂/标准 SRT，不在画面中央叠廉价字幕胶囊。

### 3.2 16:9 画幅保护铁律（EP03 头号教训）
- 任何 **16:9 横屏成片、软件界面录屏、终端窗口、网页主体**，装入容器时**宽高比不得低于 `1.35:1`，画面有效宽度裁切不得超过 `15%`**（`kit check` 自动拦截超限裁切）。
- **`split-compare` 双片对比标准版式**：在 1920×1080 舞台上并排或微错落摆放两个**完整 16:9 视窗**（常规态各约 `860×484`，圆角 12px + 深邃投影 + 顶部 `A / B` 标签）；旁白讲到 A 时，A 视窗平滑放大至 `1040×585` 居中偏左、B 压暗至 `0.35` 退后；讲到 B 时反之；倒计时与双章揭晓时双窗等大并列，观众能把两边画面的构图和细节看得一清二楚。

### 3.3 精密图解代替手搓贴画（`blueprint-diagram`）
- 讲流程、系统分工、因果链路、前后结构对比时，一律调用 `blueprint-diagram`（支持 `flow` 横/纵流向、`hub` 中心发散、`layers` 堆栈分层、`versus` 结构映射）：
  - 组件自带精密微网格、等宽编号角标、平滑动态绘线（`stroke-dashoffset` 随口播推进）、节点高光激活与镜头轻微跟焦；
  - 执行代理只传 `{topology, nodes:[{id, title, sub, tag, at}], edges:[{from, to, label, at}]}`，不准手写零散 `<div>` 方块或简陋 emoji 充当示意图。

## 4. 节奏、运动与换幕量化指标（逐章核对）

1. **切幕与对位**：
   - 单镜时长 `1.8–8.0` 秒（快切蒙太奇单刀 `0.5–0.9` 秒）。超过 8 秒的操作录屏必须快进等待段（右上角自动带 `×N 快进`）或拆成“全景定位 → 特写结果”两镜。
   - 换幕点 = 下一句首字时间 `− 0.2` 秒；镜内关键动作（印章落下、划线排除、差值弹出、焦点框锁死）严格绑定 `voice-timing.json` 的字级锚点 `@词`。
2. **镜内持续生命力（零死帧）**：
   - 每个镜头全程带线性 `drift`（`1.00 → 1.06~1.12` 或反向拉回），且入场后至少有 1 个锚点触发的二次视觉事件。
   - **源画面近静止红线**：视频类素材在镜头内的源画面不得出现连续 `> 1.8` 秒无实质内容变化（指针不动、画面不滚、人物不动）；若原录屏处于思考等待，必须裁掉等待段、倍速快进或切走。
3. **全片变化率与素材多样性**：
   - 有效视觉变化率 `≥ 0.50` 次/秒；
   - 素材来源至少覆盖 4 类（真实录屏/拍屏、网页/文档实证、图库/实拍视频、`image2` 概念图/道具或 `ltx2` 生成动态镜头、数据驱动精密图解）；
   - 相邻两镜不重复同一版式骨架，单章同一组件最多 3 次。
4. **上屏文字精简**：
   - `footage-bigword` 大字只放 1–4 个核心字（如“素”“真凶”）；组件标题只放 2–8 字短词，不带句末标点，可读字高一律 `≥ 28px`（1080p）。

## 5. 节拍表格式（`beat-table.md`）

剪辑前或边产边填时，每镜必须在 `beat-table.md` 落一行可核查记录：

```markdown
| 镜号 | 句号 | 时间 | 画面里看得见的具体事物 | 生产方式（现成 / produce-asset 命令） | 组件 recipe | 镜内锚点动作 | 隐私打码核对 |
```

表末附：
- **整期工具与预算汇总**：Modal 调用次数与免费额度消耗、`image2` 金额（`≤ $5`）、图库 API 次数（`≤ 60`）、实拍/录屏/生成/图解各自时长占比；
- **门禁自检结果**：`kit check --rendered` 0 error 证明。
