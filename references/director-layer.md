# 导演层规范 v3：原生 HyperFrames 镜头语言与头部博主实证编排

> 基于 Fireship、Vox、Johnny Harris 及中文头部科技/教程博主（FredTalk、松小鼠、木子、法可士）逐帧拆解，并经本频道 60 秒双盲实测验证。核心原则：**不套死板 JSON 预制盒，直接在原生 HyperFrames 中用真实物证、局部推近、呼吸留白与清晰大字讲清每一句话。**

## 1. 逐句「画面需求 → 真实物证」路由表（分镜阶段必填）

写任何 HTML 代码前，先建 `shot-plan.md`，按口播句组逐段确定**观众这一秒看到什么真东西**：

| 口播语义场景 | 头部博主标准画面（观众看见什么） | 首选采集工具 | 原生 HyperFrames 编排手法 |
|---|---|---|---|
| **提工具 / 框架 / 开源项目 / 论文 / 价格** | 真实官网、GitHub 仓库/PR diff、官方文档原句、定价表、榜单页面 | `record-web-cam.sh` 或 `collect-entity.sh` | 窗口微带阴影居中 → 平滑滚到目标处 → **镜头 `1.7x–2.2x` 推近 + 荧光色块划出关键句** + 左上角真实域名角标 |
| **展示产品效果 / 多方案横评 / 行业现象** | 产品官网内嵌高清 `<video>` 演示，或 **9–15 张真实案例/仓库/快讯组成的证据墙** | `collect-entity.sh` + `record-web-cam.sh` | 先铺开 `3×4` 真实证据矩阵墙缓慢横移（建立“量很大/试了很多”的冲击力）→ 镜头猛推近锁死其中 1 张核心证据 |

## 2. 四大核心高级感技法（直接写进原生 HyperFrames 工程）

### 2.1 Screen Studio 级虚拟摄影师跟焦（告别全景小字死录屏）
- 任何网页或软件录屏，**严禁 `1920×1080` 原尺寸静止平铺超过 `2.0` 秒**（观众在手机或小窗根本看不清 14px 小字）。
- 做法：外层包一个 `.cam-rig` 容器，根据 `record-web-cam.sh` 输出的 `cursor-track.json`（含每次点击/高亮的 `{t, x, y, rect}`）：
  - 全景建立位置（`0.4s`，`scale: 1.0`）→ 用 `power3.inOut`（`0.45s`）平滑推近至目标区域中心（`scale: 1.65 ~ 2.1`），讲完再平移到下一个操作点或拉回；
  - 关键按钮/数字落点叠加**手绘感红色椭圆 SVG 描边**（`stroke-dasharray` 12 帧一笔画出）或半透明荧光笔横刷高亮（`scaleX: 0 → 1`）。

### 2.2 多宫格「真实证据墙 → 单点推近」（解决“素材单薄感”的核武器）
- 当旁白出现“做了两期”、“试了好几个工具”、“抓错了好几个嫌疑人”、“量了别人的视频”、“一个 AI 团队”这类集合概念时，**不要只放一张孤零零的卡片**：
  - 将采集到的 `6 ~ 12` 张真实截图/录屏缩略窗排成微透视网格墙（`gap: 20px`，部分窗口内实时播放 muted 视频片段），让观众一眼感受到扎实的工作量；
  - 旁白点名具体对象时，网格其余项压暗至 `opacity: 0.25`，相机直接 `zoomThrough` 推入被点名的那扇真实窗口并放大至可读尺寸。

### 2.3 叙事留白、冷暖交替与干净剪辑（严禁花哨转场）
- **留白保真**：剧本标明的对比观察（如先看左边 2 秒、再看右边 2 秒）、提问后 `3.0s` 倒计时、章末 `0.4s` 黑场 + 片名大字页 + 章节扉页，必须在总时长中给足呼吸空间（例如 40 秒纯口播自然展开为 `56–62` 秒成片），绝不把口播死顶成赶火车。
- **冷暖舞台交替**：
  - **调查/实操主舞台（约 70%–75%）**：深墨绿/暗石板精密微网格底（`#0d1412` 或 `#0f1216` + 极淡 48px 坐标暗格 + 光学暗角），大字用温润米白 `#f2ece1`，唯一高饱和点缀色用朱砂红 `#e84530`；
  - **章节扉页 / 档案审片台（约 25%–30%）**：暖米纸档案底（`#ebe3d2` + 细微纸纹，深墨黑宋/黑体大字 + 红色实体印章如 `[退回]`），冷暖切换瞬间洗掉视觉疲劳。
- **转场克制铁律**：**90% 以上镜头使用干净硬切（`cut`）或同一主体变形延续（`carry`：窗口放大变成下一场舞台）**；**严禁使用**马赛克方块擦除（`pixelate`）、花哨旋转、廉价闪白！

### 2.4 常驻内嵌字幕 + 16:9 画幅保护
- **常驻底部内嵌字幕**：在 `1920×1080` 画布底部安全区（`bottom: 46px`）常驻单行居中内嵌字幕（字号 `36–40px`，思源黑 Bold，米白字配柔和深色半透明底衬或清晰暗描边，每屏 `10–18` 字），确保用户直接点开 MP4 无需外挂字幕即可顺畅观看；同时仍导出一份同步 `.srt` 备查。
- **16:9 画幅铁律**：任何横屏录屏、网页、成片样片装入窗口时，容器宽高比必须 `≥ 1.35:1`（标准 `16:9`），**严禁把横屏视频竖切成窄条导致左右内容被裁断**。

## 3. 声音设计铁律（视听一体）
- **BGM 侧链闪避**：选用克制有律动的现代电子/纪实底乐，口播发声段自动压低至 `-22 ~ -26 dB`，无口播留白段（如开场看片、3 秒倒计时、章节扉页）自然回升至 `-12 ~ -14 dB` 撑满气场。
- **物理动作音效**：每次推近聚焦配轻柔低频 `whoosh`、荧光划线/弹窗配清脆 UI `tick`、倒计时配秒表 `click`、印章落下配厚重 `thump`、代码终端配轻微机械键盘纹理；整片母带综合响度严格归一至 **`-14.0 LUFS ± 1.0 LU`，真峰值 `≤ -1.0 dBTP`**。
