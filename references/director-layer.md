# 导演层：从旁白到画面

导演层是我们跨期复用的核心资产。输入是 script.md 加 voice-timing.json，输出是 beat-table.md（给人审）和 beats.json（给 build.mjs）。

## 1. 切幕

- 一幕通常对应 1–2 句，时长 2.5–10 秒。超过 10 秒的录屏要压缩：等待段快进，或者跳切。
- 换幕点 = 下一句首字时间 − 0.2 秒。非硬切入场时提前 0.5 秒叠化。动作要对准句内锚点词（`anchors`）的时间。
- 第 0 帧必须已经有主体。它同时是缩略图和停留率的第一眼。
- 最后一幕至少 2.5 秒，收在一个稳定画面上。

## 2. 每幕先问：这句话要观众做什么？

| 观众要做的 | 首选配方 | 备选 |
|---|---|---|
| 看真实操作 | B族：device-stage / laptop-3d / filmed-screen / cursor-zoom | rec-zoom（固定框推近） |
| 读证据或官方原文 | A族：news-card / social-post / chat-bubble | doc-zoom |
| 认识一个东西 | photo-word（实物特写 + 大字 + 测量小签） | stock-shot |
| 清点 / 花了多少 | ledger、checklist | desk |
| 看关系 | rope-map | desk |
| 理解变化或对比 | num-split、step-ruler | strike-slips |
| 否定一个误区 | strike-slips | single-line |
| 情绪或场景过渡 | stock-shot | single-line |
| 章节切换 | chapter | step-ruler（三步章节回扣） |
| “画面是代码写的” | editor | rec-zoom |
| 全景铺陈（≥5 件物件） | desk | — |
| 一句强调（极疏） | single-line | — |
| 还没录屏的“对 Codex 说一句话” | prompt（只能临时用，最终要换成真录屏） | — |

配方的字段和示例在 kit `docs/recipes.md`。缺配方时，先查 HyperFrames registry（hyperframes-registry skill），再考虑新写，新写的要回写进 kit。

## 3. 五种槽位与组合

每幕从下面挑 2–4 个组合：

- **A 物件**：照片、透明道具、截图、文件页，可以叠两三件；
- **B 主文字**：宋体大字或大数字；
- **C 结构**：台账、清单、时间线、刻度尺、关系网；
- **D 标注**：荧光、蓝圈、红章、划线、绳；
- **E 小字**：眉标、文件名 · 时长、出处、参数。

出场顺序固定：物件 → 主文字 → 结构 → 标注 → 小字。相邻两步间隔至少 0.4 秒，整组落在旁白锚点附近。

版式族至少 12 种，轮换使用：左图右字、右图左字、字压图、大字 + 角落小照片、照片居中四周绳连标签、两卡对开、清单卡 + 侧边照片、时间线 + 照片落点、满幅文献 + 局部荧光 + 角落小图、物件堆叠、标题跨物件、空白纸上单句。

## 4. 节奏规则（量化，逐章核对）

1. **景别**：每章至少 1 个特写（主物件占画面 >60%）、1 个全景（≥5 件物件）、1 个满幅（屏幕或文献铺满）。相邻两幕景别不同。
2. **密度**：极疏、中、极密交替，不准连续三幕都是“中”。
3. **层次**：每章至少 2 幕有三层叠放（桌面 → 纸或屏幕 → 照片、便签、胶带）。
4. **幕内运动**：入场后至少还有 1 个动作：推近、平移、荧光扫、章盖下、纸被抽走。不准入场后就静止到切走。
5. **转场**：至少一半换幕不是硬切，可用平移（pan）、推进物件内部（push）、拿走露出下一层（lift）、匹配剪（match）。
6. **配方轮换**：相邻两幕配方不同；每章至少用 4 种配方。
7. **舞台**：每幕单独指定。首批新配方只用 charcoal 深炭、paper-warm 牛皮纸、paper-cool 冷白；旧配方的 paper-gray 仅保留兼容。每章深炭最多约 40%，同一舞台连续最多 3 幕。
8. **色彩焦点**：每章一个，用素材自带的颜色（彩色配图、屏幕 UI、牛皮纸），其余保持低饱和。

EP01 实际配方分布可作参考：rec-zoom 16、photo-word 12、strike-slips 6、doc-zoom 6，desk、step-ruler、stock-shot、chapter、num-split 各 4，single-line 3，editor、checklist、rope-map 各 2，ledger 1。

首批视觉词汇的使用规则：

- 每期至少用 2 种 B 族容器装录屏，`kit check` 自动拦截不足项；连续两段录屏不能用同一种装法。
- 标题条可选：单期至少40%镜头不出左上标题；素材满画面、3D设备、图墙、金句和录屏容器优先关闭 `props.showTitle`。同一版式骨架最多连续3镜，不能只换配方名字。
- 转场时旧标题和来源先退场，再进入新标题；根据检查器的阅读建议分配停留，长需求原文优先获得时长。
- rank-race只用于至少两帧的真实排名观察，静态数值对比用bar-compare。终端30px、至少6行高，红章盖纸色签；对比柱宽140px，测量差值从原始数据计算。
- 数字、新闻、别人说的话等有依据的论点，优先用 A 族证据，不用 image2 代画证据。
- image2 只做现实里拍不到的比喻画面、物件道具和封面。
- 新配方第一次出现，节奏放慢 20%，给观众看清结构的时间。
- `headline-slam` 每章最多 1 次；`chromatic-aberration-wipe` 每期最多 1 次，只用在问题/翻车处，颜色仍限定为功能色。
- 转场选 directional-wipe、cinematic-zoom、grid-pixelate-wipe、halftone-dissolve、flash-through-white、chromatic-aberration-wipe，统一 0.5 秒；不用 glitch、gravitational-lens、domain-warp。
- 质感层只选 grain-overlay（默认 0.06）、light-sweep-pass、notification-stack；不引入霓虹、星空或雪花背景。质感层不计入配方使用次数。

## 5. 上屏文字

- 大标题只用 2–8 字的关键词或数字，不带句末标点。整句旁白不上屏，字幕走 SRT。
- 1080p 下可读字至少 28px。截图里的字太小，就推近或只取局部；做不到就改用卡片转述。
- 纯文字幕每章最多 1 个。
- 同一素材（道具、照片）全片最多出现 2 次，两次语义要一致。被否定过的样图不能再当正面素材用。
- 所有元素距画面四边至少 64px，不准出现被切掉的半个单词，也不准有孤立的字符。
- 标题写入动画在 0.3 秒内完成，不留“写了一半”的帧。
- 不准有空卡：卡片高度随内容长，台账按旁白逐行累加。

## 6. 节拍表格式（beat-table.md）

```
| 幕 | 句 | 时间 | 配方 | 舞台 | 景别 | 密度 | 层数 | 幕内动作 | 入→出 | 素材类 | 素材 | 屏上关键词 |
```

表后附两节：
- **统计**：素材类时长占比、各配方次数、各舞台占比；
- **待换素材**：占位清单，只记录在这里。

中心逐行核对第 4 节和第 5 节的规则，核对过才进入渲染。
