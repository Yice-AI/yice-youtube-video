# 导演层规范 v4.0：「一策看片室」统一编辑部美学、满屏跟焦与实物步进

> 经双盲 60 秒盲测（`盲测-A` 获胜）与 `v3` 反例（因扔掉统一编辑部美术、乱铺满屏图库空镜壁纸、堆砌 12 宫格蚂蚁字白窗而翻车）正反对照确立。
> 核心准则：**全场守住「一策看片室」唯一视觉世界；每一句话只把 1 件最硬的真实录屏或第三方物证放进四角 L 型取景框里放大看清，绝不拿图库视频糊墙，绝不贴碎小框膏药。**

v4.0 在保留 v3.1 接口的前提下增加三种可组合的导演原语。`add_fullbleed_rig` 将真实录屏铺满 1920×1080，按多个操作点连续推近并可叠加一笔红圈、箭头、聚光灯和右上清单。`add_print_desk` 把概念截图做成有留边、倾角和投影的相纸卡片，按旁白节点逐件拍落。`add_captions` 默认使用通透无黑盒字幕，`add_music_drops` 为反转句登记底乐瞬抽窗口。每个原语都会把布局、beats、素材和动作音效写入 `shot-timeline.json`，供 `audit-v3.py --v4` 检查。

## 1. 统一美术母版（`$KIT/editorial/editorial.py`）

全片所有镜头必须共享同一套编辑部平面与色彩秩序，禁止中途变成无衬线白板 PPT 或图库混剪：

1. **双底色秩序（全片仅此两种舞台底色）**：
   - **主调查/看片舞台（占 80%–85%）**：深松墨绿径向暗场（`#243531 → #172322 → #111a19`）叠加 `100px` 低透明坐标网格（`#465750` `opacity=0.30`）；主标题为温润象牙白衬线粗体（`#f6f0df`，`serif 800`），档案编号与说明为鼠尾草等宽字（`#b5c9a9`，`monospace`），唯一高饱和点缀色为珊瑚朱砂红（`#ff745a`）。
   - **章节扉页与审片裁决台（占 15%–20%）**：暖米档案纸底（`#e7ddc5`）配深松墨黑衬线大字（`#172322`）与实体印章（`#a03528` 线框印章 `[退回]`），在章节转折与高潮裁决处切换，瞬间刷新视觉呼吸。
2. **五大标志性编辑部构件（`kit/editorial/editorial.py` 内置）**：
   - `mast(label, tag)`：顶部 `y=77` 常驻刊头（`一策 | 看片室 / 制作记录 / 样片档案 / 逐帧调查 / 测量记录 / 案发现场` + 右端等宽英文场记码 + `y=109` 细分割线）；
   - `printframe(x, y, w, h, tag, badge)`：四角 `32px` L 型取景框 + 左上等宽样片标签 + 右上来源域名角标；
   - `rule(x, y, w)` + `.scan`：`20px/100px` 精密刻度尺与珊瑚红扫描游标；
   - `caseleft(eyebrow, lines, desc)`：左栏 `84..540px` 衬线大字论点脊柱，右侧 `570..1820px` 留给完整的 `16:9` 大号实证视窗；
   - `.cap span`：底部 `44px` 常驻深墨底珊瑚红下划线字幕条（`42px` 粗黑体，单屏一句完整短句）。

## 2. 逐句「画面需求 → 取景框实证」路由表

| 口播语义场景 | 观众在取景框里看见什么真东西 | 采集工具与视口要求 | 版式与运镜做法 |
|---|---|---|---|
| **前后两版成片 / 效果对比** | 两段完整 `16:9` 真实成片画面 | 本地已渲染真实样片 | **先单看后并排**：先左片大框单播 `2.0s` → 再右片大框单播 `2.0s` → `A/B` 双 `16:9` 取景框并排（期间换 2–3 组真实片段保持动态）+ `3s` 圆盘刻度倒计时 + 珊瑚红印章盖下揭晓 |
| **提工具 / 框架 / 开源仓库 / 文档** | 真实 GitHub 仓库主页、官方文档关键段、工具主页演示 | `record-web-cam.sh`（默认 `--theme dark --scale 1.5`） | 放入右侧 `16:9` `printframe`（或 `A/B` 双框对照两套工具），自动深色模式 + `150%` 大字号平滑滚动并珊瑚红划线高亮，左上角标真实域名（如 `github.com/heygen-com/hyperframes`） |
| **核心实测数字 / 测量对比** | 左侧超大衬线实测数字（如 `12.25 小时`、`0 发布`、`5% vs 73%`）+ 右侧对应真实证据视窗 | 实测底账 + 真实构建日志 / 逐帧时间轴录屏 | 数字与物证同台印证：绝不只放孤零零的数字空网格，右侧 `printframe` 同步播放暗色调和后的真实构建耗时日志或时间轴逐帧测量实录 |
| **排查错误方向 / 拆解原因** | 左栏衬线结论 + 珊瑚红删除线划掉错误项 + 右侧真实参数/剪辑面板录屏 | `record-web-cam.sh` 或剪辑软件实录 | 右侧 `printframe` 展示真实 FFmpeg/时间轴参数界面，视窗做 `1.0 → 1.12` 克制推近，**禁止手画歪斜红圈糊在正文上** |
| **多工具协同 / 团队分工** | 先用 3 张等宽 `16:9` 取景卡总览分工，再连续硬切换入每个工具的大号实操视窗 | 打码静态图（Claude）+ `codex-live.mp4` + `record-web-cam.sh` | **主体延续（Carry）**：总览最多 `3` 扇干净视窗；随后固定左栏角色标题位与右栏大号 `16:9` 取景框位，依次干净硬切展示 `Claude 派单 → Codex 终端执行 → Playwright/Harness 自动取景` |
| **片名页 / 章节扉页 / 审片盖章** | 光学胶片齿孔片名页、暖米纸章节扉页、`[退回]` 裁决印章配问题样片 | `perforations()` / `PAPER` / `stamp()` | **守住叙事留白**：片名页与章节扉页保持纯粹高级的平面张力，**严禁在片名页和扉页背后塞图库视频壁纸** |

## 3. 四条审美红线（直接决定成片像高级纪录片还是廉价拼贴）

1. **严禁满屏图库空镜壁纸**：禁止把 Pexels/Pixabay 实拍视频（卡尺、胶片、镜头、机房）铺满 `1920×1080` 当背景底图；科技教程频道的高级感来自**干净深松墨绿画布 + 框内高锐度真实界面**。
2. **严禁超过 3 扇视窗的碎框堆砌**：废除 `3×4` / `9–12` 宫格缩略图墙；每场戏只给观众 **1 个视觉焦点**（或 `A/B` 对比双焦点），框内主体字高必须清晰可读。
3. **严禁刺眼纯白窗口直贴深色底**：
   - 网页录屏一律默认深色模式（`record-web-cam.sh --theme dark --scale 1.5`）；
   - 无法开深色模式的静态白底截图（如 Claude 派单图）加 `.tone-paper-tint` 暖纸柔化，纯白底小字终端日志加 `.tone-invert-log` 转为深色暗底，且缩放绝不裁断标题边缘文字。
4. **音画一体与原速人声**：
   - 人声 `100%` 原采样率 `1.000x` 落盘，严禁 `atempo`；
   - 原创纪实脉冲底乐随人声包络自动闪避，倒计时配秒表滴答、切换配克制低频帧响、印章落下配扎实重音，综合响度锁定 **`-14.0 LUFS ± 0.8 LU`**。
