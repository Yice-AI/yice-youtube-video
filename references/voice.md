# v15.0 旁白制作与签发

## 稿件与生成

剧本使用由 `narration.md` 母稿经 `kit/scripts/split-narration.sh` 拆出的 `script.md`（章标题和 `| 幕号 | 旁白 | 画面 |` 逐幕表格），改口播只改母稿再重拆，配音前先通过 `kit/scripts/precheck-episode.sh --project . --stage script`。只朗读旁白列，`〔画面：…〕` 是画面规划注记，`〔核：…〕` 是底账注记；专有名词或多音字可用 `原词〔读：同音词〕`（如 `归藏〔读：归葬〕`），仅在合成音轨时按注音朗读，字幕与正文对齐仍保留 `原词`。用口语表达数字与动作，把容易误读的多音字改写成无歧义的词组。中文汉字和标点两侧的多余 ASCII 空格会在拼接与提交前清理，英文词间空格保留。

- 正片优先明确指定已授权的免费或低成本云端 GPU。Kaggle 用 `--backend kaggle --speed 1.0`，可用 `--tts-model` 在已部署的开源语音底座间切换（默认沿用当前精修模型）。客户端提交 `/tts_async` 后每 2.5 秒查询任务，总等待默认 900 秒，可设 `YICE_TTS_TIMEOUT`。仅提交接口返回 404 才回退同步接口。
- `long_paragraph` 只在中文句末分组，优先每段 65–115 字、至多五句。保留自然句界，单句超过 115 字先修稿。每个短段完整交给模型，参考音色由服务端缓存。
- 单句离线补录可明确使用 `--backend local --allow-slow-local`。Modal 仅在获得明确授权后显式指定 `--backend modal`。参考音频只通过已授权的 HTTPS 配音端点传输。
- 已明确选择的 Whisper 模型优先，其次是 `YICE_ASR_MODEL`、含有效权重的本机目录、离线 Hugging Face 缓存。保留原声 WAV 与对齐记录。

```bash
kit/scripts/voice.sh script.md --backend kaggle --speed 1.0 --output voice
kit/scripts/voice.sh --concat-wavs part-a.wav part-b.wav --pause 1=3.0 --output chapter.wav
```

## 呼吸与音轨

配音保持 1.000× 原速，禁止给成片人声加 `atempo`。拼接去除逐段直流偏置，首个有声采样晚于 50 毫秒时修剪文件开头的 25 毫秒解码瞬态。在拼缝用 110 毫秒前导和 130 毫秒尾音的半余弦包络。底噪候选排除周期性静音窗口，写盘前以 −68 dBFS 底噪托底。禁止句间插入 `np.zeros` 或用 −40 dB 门槛切掉自然吸气。设计停顿可用 `--pause-after 0-3=3.0` 或拼接时的 `--pause 1=3.0`。

`--profile natural_v7` 允许自然连读，句末和转折 0–1250 毫秒，普通逗号 0–950 毫秒；句内无标点停顿上限收紧到 165 毫秒，词内能量塌陷 ≥ 16 dB 且持续 110–260 毫秒、句中犹豫拖音同样拦截。`voice.py` 发现异常分段自动换 seed 重抽，最多 3 轮，仍不过的分段在报告里列出待补录。设计停顿允许比目标短 150 毫秒或长 600 毫秒。实质漏读、错读或卡顿按完整自然句补录，重新对齐并复听拼缝。全片母带由装配器做响度与真峰值校准。

## 签发前逐章听审

Whisper 会根据上下文补猜，多音字听错、句间粘连和吞尾字都可能通过文本检查。签发人或能直接听辨音频的多模态审片者须逐章抽听关键多音字和句尾，并登记时间戳：

- 确认「差 chā/chà」「地 dì/de」等词在上下文中的读音。
- 听「做的。经理」这类句界，核对 0 毫秒是否造成听得见的破句粘连。
- 听「不是 PPT 了」这类句尾，确认「了」等弱读字仍完整。
- 复听每处设计留白和换段边界，确认呼吸和底噪连续，字幕对应实际读音。
