# 审片门槛、质感验真与已踩过的坑（v2）

## 核心教训：为什么“ASR 1.0 + pHash 0 重复”还是被用户一眼判不及格？

EP03 v4.1 证明：只靠字面对齐和去重指标，拦不住三类致命的质感坍塌：
1. **画幅乱裁**：开头把两条 16:9 横屏成片硬塞进 `957×1080` 竖栏 `object-fit: cover`，左右各切掉一半以上，画面根本看不完整；
2. **简陋贴画与死画面**：执行代理脱离成熟组件手搓 CSS/SVG 图形，贴画粗糙廉价；29 个镜头里的录屏源画面静止超过 1.5–5 秒，只靠外框微推假装在动；
3. **配音微卡顿漏检**：绝对静音阈值没触发，但句内声门发紧、能量骤降和同音滑音一耳朵就能听出来。

因此，v2 实行 **“升级版机器质感硬门（`kit check --rendered`）+ 中心 100% 原尺寸抽帧与试听审片”** 双重否决制。

## 一、机器自动硬门（`kit check` 必须 0 error 才准交审）

1. **基础规格与零黑帧/零空框**
   - [ ] `1920×1080` 30fps，带音轨，成片时长等于 episode.end（允许配音结束后留 2–4 秒结尾画面），`hyperframes check` 0 error；
   - [ ] `blackdetect` 为 0（除显式声明的片名落黑 ≤0.5s 外）；全片逐帧局部方差扫描 0 空框（杜绝 EP03 v4.1 10.2–10.7s 双栏白框类渲染空窗）。
2. **16:9 横屏画幅保护门（新增硬拦截）**
   - [ ] 任何承载 `16:9` 视频、软件录屏、网页截图的视窗容器，实际显示宽高比必须 `≥ 1.35:1`，单边有效内容裁切 `≤ 15%`；**把横屏成片竖切成窄栏的布局直接判 error**。
3. **组件纯粹门（禁止手搓简陋贴画）**
   - [ ] 业务成片开启 `strictRecipeOnly`：所有镜头必须来自 `kit/template/recipes/` 已验收组件库，禁止在镜头内塞入未登记的裸 SVG 简笔画、emoji 贴纸或平涂几何块。
4. **源画面真运动门（新增硬拦截）**
   - [ ] 对成片中所有视频素材区做去平移配准后的分块亮度变化扫描：连续 `> 1.8` 秒源画面无实质内容变化（如停在聊天结果页不动、访达列表静止）直接判 `near_static_source` error；源片尾余量不足（冻结在末帧）直接判 error。
5. **文字、去重与单调度门**
   - [ ] 可读字高 `≥ 28px`，距离四边安全区 `≥ 64px`；无截断词、无导演拍号（如 `B04-02`）、无“占位 / 临时替代 / 示意”字样；
   - [ ] 填充素材每章 `≤ 2` 次、全片 `≤ 4` 次且不复用同一入点；相邻两镜版式骨架不同；有效视觉变化率 `≥ 0.50` 次/秒；素材来源覆盖 `≥ 4` 类。
6. **五维配音与母带响度门**
   - [ ] `voice-check.py` 五维检查（ASR 实词/同音核对、句内相对能量塌陷 micro-dip、无标点犹豫、拖字/语速突变、句组接缝连续性）告警 `0` 条；
   - [ ] Demucs 校验 BGM 无人声抢戏；成片综合响度 `−14.0 ± 0.5 LUFS`，真峰值 `≤ −1.0 dBTP`。

## 二、中心人工审美与合规必检清单（不信执行者自评，亲自看物证）

中心每次审片必须亲自打开以下四样物证：
1. **全片 3 秒接触表 + 逐句首中帧接触表**（查每一句旁白说的东西在画面里能不能一眼看见、构图稳不稳）；
2. **至少 8 张关键镜头的 `1920×1080` 100% 原尺寸静帧**（涵盖开场分屏、概念隐喻镜、`blueprint-diagram` 图解镜、`ltx2` 生成动态镜、录屏特写镜、数据尺镜，放大看阴影、边缘、字重与清晰度，但凡有“AI 廉价贴纸感”直接打回重造素材）；
3. **配音重点切片波形与包络图（必要时请用户盲听小样）**（重点查开场前 5 句、长转折句、引号原话句、补录拼接处）；
4. **合规与隐私逐项红线核验**：
   - [ ] 全片 **0 帧** Johnny Harris、Fireship 等参考片原片画面或缩略图；
   - [ ] Claude 界面 **100% 为已打码静态截图**，无任何 Claude 录屏；
   - [ ] 用户名、`$HOME`/本地路径、邮箱、IP、无关会话名、手机拍屏旁屏头像 **100% 已由 `.redact` 跟随遮罩盖严**（滚动录屏抽首、中、尾三帧核对遮罩未滑脱）；
   - [ ] 全部上屏与口播数字与账本实测值逐一核对无误。

## 三、历史踩坑总账（EP01 → EP03）

| 阶段 | 踩过的坑 | 根因 | v2 永久防呆机制 |
|---|---|---|---|
| EP03 v4.1 | 开头两条横屏成片竖着切左右两栏，画面看不全 | `split-compare` 写成 `957×1080` + `object-fit: cover`，切掉横屏 >50% 宽度 | `split-compare` 改为双 16:9 完整视窗动态聚焦；`kit check` 新增横屏容器宽高比 `<1.35` 自动报错 |
| EP03 v3–v4.1 | 动效贴画简陋，整体没比裸用 HyperFrames 强 | 金样做成散装 HTML 让 Codex 复制手改，缺画面也不让调生图/生视频，执行者手搓裸 CSS/SVG | 高阶组件全部收归 `kit/template/recipes/` 参数化锁死（含 `blueprint-diagram`）；剪辑逐句调 `produce-asset.sh` 当场造高质感画面 |
| EP03 v3–v4.1 | 29 个镜头源画面静止 >1.5s，看着卡住 | 反复切回同一段静态聊天窗/访达录屏充数，外层只加微弱 `drift` | `kit check` 加入去漂移后的源画面分块运动扫描（>1.8s 静止报错）；缺动态画面当场用录屏有效段、图库实拍或 Modal `ltx2` |
