# 审片门槛与已踩过的坑

## 怎么审

中心要亲自看，不能只看执行者写的“已通过”：
- 3 秒间隔的接触表；
- 每 40 秒抽一帧拼图；
- 每个录屏幕抽 2–3 个时间点；
- 用户提过意见的幕，每一幕都要单独看。

用 kit 的 `scripts/review.sh <mp4> [--at t1,t2]`。

问题写成编号清单，每条要包含：哪一幕、看到了什么、改成什么样。发回画面会话，出下一版。

## 门槛清单（每版都要过）

**技术**
- [ ] 1920×1080 30fps，带音轨，blackdetect 结果为 0，`hyperframes check` 报 0 个 error
- [ ] 成片时长与 voice-timing 的 end 一致

**开头和结尾**
- [ ] 第 0 帧就有主体
- [ ] 最后一幕至少 2.5 秒

**画面**
- [ ] 画面里没有任何占位字样（如“待录屏替换”“STOCK SLOT”“示意”）
- [ ] 没有空卡，也没有入场到一半的空白纸片
- [ ] 可读字至少 28px；截图和录屏推近后字能读清
- [ ] 不准切掉半个单词或标签，元素离四边至少 64px
- [ ] 录屏推近时始终铺满所在区域：不露黑边，顶部不被裁掉一行

**隐私**
- [ ] 按每段录屏 index.md 里的打码清单逐段抽帧检查

**规则**
- [ ] 节奏规则逐章核对，见 director-layer 第 4 节
- [ ] 舞台配比：每章深炭最多约 40%，同一舞台连续最多 3 幕
- [ ] 同一素材最多出现 2 次；第三方素材的许可都已登记

**内容**
- [ ] 画面里的数字与实测一致
- [ ] 画面与真实录屏一致，例如权限模式变了，对应那一幕要改

## 已踩过的坑（EP01）

**路线和方法**

| 坑 | 原因 | 现在的做法 |
|---|---|---|
| 画面“素”、单调 | 抄了参考片的极简外壳，没有它的内容密度；每幕都是一张卡加一件道具的中景 | 屏幕当主体；每章 3–5 件新素材；节奏规则量化执行 |
| 做模板又慢又贵 | 在 Remotion 上从零手写五六十个组件 | 路线 C：用 HyperFrames 渲染，只做导演层加配方 |
| 每期都是灰底加剪刀 | 把版式和道具做成了固定搭配 | 五槽位组合、版式族轮换、四种舞台 |

**画面细节**

| 坑 | 原因 | 现在的做法 |
|---|---|---|
| 开场第 0 帧全黑 | 入场动画从空画面开始 | 第一幕设 static，第 0 帧主体就已在位 |
| “本期账单”大半张是空卡 | 卡片高度固定 | 卡片随行数长高，行随旁白逐行累加 |
| 网页截图左边被切成“ocs” | 推近时取景越出了截图范围 | 截图整块放进卡片，或推近到一个完整的局部 |
| 录屏下方露黑带、顶部切掉一行 | device 框的相机中心没有限制 | 把相机中心夹在录屏范围内 |
| 字体换台机器就变样 | 用 `local()` 引用字体 | 字体文件打包进 assets/fonts，用 @font-face 引用 |
| 欧元现金、紫色背景的图库图出戏 | 只看了主题词，没看观众和色调 | 素材要贴合中国观众，并且低饱和 |

**执行和流程**

| 坑 | 原因 | 现在的做法 |
|---|---|---|
| v4 渲染完却空等了一夜 | 用 `pgrep -f "hyperframes.*render"` 判断是否结束，被残留的 headless chrome 进程匹配上 | 以命令退出或日志出现 “Render complete” 为准 |
| 会话额度用完，任务停在半路 | Claude 会话有 5 小时额度上限 | 重置后从断点继续；中心发消息唤醒 |
| 录屏会话结束这一轮后，没人唤醒它 | 子会话不会自己醒 | 等待类任务要求它在本轮内自己轮询，最长等 30 分钟 |
| 透明道具出不来 | image2 默认没有 alpha 通道 | 加 `--background transparent`；不支持时退回 Pillow 色距抠图 |
| “点允许”那一幕录不到 | Codex 处在完全访问模式，不会弹确认 | 录前先问用户用哪种权限模式；脚本跟着实际情况改 |
| 背景音乐里藏着人声，和配音抢耳朵 | music_gen 的出曲没做人声检查 | 入选前跑 Demucs 机测；不合格用伴奏轨复测，别直接用原曲 |
| v5 渲染时用的还是旧音乐 | 音乐还在复测，渲染会话已经先开渲 | 画面可以先审；换音乐时只重混音轨（视频流直接复制），不重抓帧 |
| ASR 全过、静音也干净，用户听着还是卡（v6 有 6 处） | 只查了“字对不对”和“静音多长”，没查拖字、句中降调；稿子语序别扭、中英之间加了空格；逗号停顿一刀切压到 250ms | 写稿按 `references/voice.md`，生成后跑 `voice-check.py`，停顿按语义分档，有问题的整句替换 |
| Codex 跑完检查就结束了这一轮，没渲染也没报完成，状态停在 working 78 分钟 | 长任务中途，执行会话自己结束了这一轮 | 中心看 progress 心跳超过 30 分钟、而产出文件没更新时，去查会话记录有没有 task_complete；有就写接续指令，请用户说“去读最新指令文件” |
