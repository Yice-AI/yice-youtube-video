# 一策 Frame 规范

## Overview

一策的视频是"真实操作的档案"。教程的价值和科技感都在屏幕上，所以录屏是主体；图解只负责把一句话里**观众要做的事**摆清楚。画面像一张有光照的工作台：屏幕、纸卡、实物、胶带、刻度尺都是真的物件，镜头在台面上移动、推近。

## The Frame

- **背景永远不是平板色**。三种舞台都有光照场（左上窗光、右下压暗），再叠纸纤维（深炭舞台叠极淡布纹）、48/240 细网格、上沿和左沿的刻度尺、四角对位标、左下角等宽时间码。环境动态只做三件事：窗光缓慢漂移、刻度尺缓移、时间码走字。
- **前景要有细节**：每件主物件旁边至少一个等宽小签（文件名、时长、参数、出处），用 1px 引线连到物件上。
- **一个视觉重心**：大字或主物件占画面 35–70%；其他东西都服务它。对齐到 48px 网格，同一幕的元素共享一条边线或基线。

## 舞台用法

| 舞台 | 用在 | 色彩焦点 |
|---|---|---|
| charcoal 深炭 | 开场钩子、章节页、结论 | 屏幕 UI 的亮光 / 彩色配图 |
| paper-warm 暖米 | 钱、电脑配置、清点 | 牛皮纸、价签、黄荧光 |
| paper-cool 冷白 | 装软件、建项目、操作步骤 | 屏幕 UI |
| paper-gray 灰纸 | 过渡、对比、数字卡（v2 新增，打破暖/冷/炭轮换） | 道具与数字 |

满幅录屏时舞台只露边缘（或完全不露），但时间码、角标照常在最上层，保证全片是一个系统。

## Composition Rules

1. 先看这句话要观众做什么，再选配方：识别主体 → 照片 + 大字；读证据 → 录屏/页面推近 + 荧光；看关系 → 关系连线；理解变化 → 数字对开 / 步骤刻度尺；否定 → 划线纸签；清点 → 清单卡 / 台账。
2. 出场次序固定：物件 → 主文字 → 结构 → 标注 → 小字。
3. 大标题只写关键词；完整短语只出现在卡片里（≥ 28px）。
4. 录屏推近时，焦点外区域轻度虚化（6–8px）并压暗 8%，焦点内用荧光扫关键句。

## Do

- 用真实截图、真实录屏、真实实物照片；数字来自实测。
- 用刻度、坐标、时间码、测量线表达"精密"。
- 每幕入场后还有一个动作（推近 / 平移 / 荧光 / 章 / 抽走）。

## Don't（禁用清单）

- 霓虹发光、故障/RGB 抖动、粒子、全息线框、赛博配色、渐变光晕标题、`background-clip:text` 渐变字。
- 平涂色块冒充物件；全局叠噪点冒充质感（纸纤维只属于纸）。
- 纯 #000 / #fff 背景；全屏线性渐变（压缩会出色带）。
- 整句旁白上屏；大标题带句末标点；可读字 < 28px。
- 相邻两幕同一配方 / 同一景别；连续三幕中等密度；同一素材出现 3 次以上；被否定的样图当正面素材。
- 卡片网格（同尺寸卡片平铺）、一律居中、所有元素同一种入场。
- 只用慢动作、入场后静止到切走。


## v2 修订（2026-11-15，中心审片后）

- 舞台不再“一章一种”：每幕在 beats.json 里单独指定，每章炭色 ≤ 40%，同舞台连续 ≤ 3 幕，白纸 / 牛皮纸 / 灰纸轮换。
- 屏上可读字一律 ≥ 28 px（1080p）。装饰层（刻度、元数据）按 micro 处理，写了 `data-layout-ignore`。小字要么推近到 ≥ 28 px，要么改成大字卡转述。
- 占位字不上屏（`.yf-ph` 在 CSS 里 display:none）；待换素材只写在 report.md / beats 里。
- 距画面四边 ≥ 64 px；标题 2–8 字，写入动画压到 0.3 s 内完成，不留“写了一半”的帧。
- 道具阴影统一朝右下（光从左上来）；每件道具全片最多出现 2 次。
- 字体全部打包（assets/fonts + @font-face），不依赖 `local()`。
